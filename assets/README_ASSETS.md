# AURORA individual visual reference assets

This package contains individually organized visual reference images for the AURORA — Lunar Outpost Survival Simulator frontend.

## Important asset status
These are generated concept/reference assets intended to guide the coding agent's visual design. Some images may retain a dark background, framing, or compositional details. They are not guaranteed to be transparent, animation-ready, or production sprite sheets. Inspect and adapt them before use; do not assume every image is a clean game-ready cutout.

## Character naming — authoritative
The agriculture and research specialist is **Maya Quinn White**.
Use `characters/maya_quinn_white.png` and the exact display name `Maya Quinn White` everywhere in the game, source code, UI, dialogue, documentation, and prompts. Do not use Maya Khan or Maya Quinn.

## Folders
- `logos/`: AURORA and outpost logo concepts.
- `characters/`: four crew portrait references.
- `suit_assets/`: astronaut suit, helmet, gloves, boots and backpack concepts.
- `buildings/`: base building references for the drone-view map.
- `environments/`: first-person interior scene references.
- `backgrounds/`: welcome, home, briefing and control-room scene references.
- `events/`: emergency illustration references.
- `icons/`: resource and warning icon references.
- `ui/`: panel, button and progress-bar style references.
- `map_elements/`: drone-map overlay references.
- `misc/`: Moon, Earth, space, hologram and day-counter references.

## Intended project destination
Copy the entire `assets/` directory into `AURORA/public/assets/`.
